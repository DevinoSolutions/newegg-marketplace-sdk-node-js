# @devino/newegg-marketplace-mcp

A Model Context Protocol (MCP) server exposing safe, narrowly-scoped Newegg Marketplace
tools (inventory, prices, orders, reports, RMAs and refunds, catalog and reference lookups, listing
creation) over **stdio** and **Streamable HTTP**. Built on
[`@devino/newegg-marketplace-sdk`](../sdk/README.md), it is designed for language-model callers acting
on a real seller account: tool descriptions are treated as hints, not security, and every
constraint is enforced in handler code.

- **Read-only by default.** No write tool is registered unless
  `NEWEGG_MCP_ALLOW_WRITES=true`.
- **Preview → apply writes.** A model must produce a reviewable plan and a single-use,
  TTL-bounded `previewId`; apply takes only that id and cannot change the plan.
- **No order writes.** Shipping or cancelling orders is SDK-only; no MCP tool exposes it.
- **No credentials via MCP.** Callers can never supply credentials, base URLs, hostnames, or
  `Overwrite` values; raw upstream Newegg bodies never cross the boundary.

> The `@devino` scope is a placeholder chosen to be easy to find-and-replace before publishing.

## Requirements

- Node.js >= 22.12.0, ESM only.
- Targets the stable MCP SDK line (`@modelcontextprotocol/sdk@^1.29.0`), spec revision
  2025-11-25. The v2 SDK (beta) is deliberately not used.

## Installation

```bash
npm install @devino/newegg-marketplace-mcp
# or run without installing:
npx -y @devino/newegg-marketplace-mcp
```

## Running

### stdio (default)

The MCP client launches the server as a subprocess. Example client configuration:

```json
{
  "mcpServers": {
    "newegg-marketplace": {
      "command": "npx",
      "args": ["-y", "@devino/newegg-marketplace-mcp"],
      "env": {
        "NEWEGG_SELLER_ID": "${NEWEGG_SELLER_ID}",
        "NEWEGG_API_KEY": "${NEWEGG_API_KEY}",
        "NEWEGG_SECRET_KEY": "${NEWEGG_SECRET_KEY}",
        "NEWEGG_MARKETPLACE": "us",
        "NEWEGG_CREDENTIALS_MARKETPLACE": "us"
      }
    }
  }
}
```

Replace the `${...}` placeholders with real values (or inject them via your client's secret
mechanism) — never commit real credentials. On stdio the server logs strictly to **stderr**;
stdout carries only the JSON-RPC protocol.

### Streamable HTTP

```bash
newegg-marketplace-mcp --transport http
```

- Binds `127.0.0.1:3919` by default and **refuses to bind a non-loopback host unless
  `NEWEGG_MCP_HTTP_BEARER_TOKEN` is set** (at least 32 characters). It speaks plain HTTP: front it with a
  TLS-terminating proxy and set `NEWEGG_MCP_HTTP_BEHIND_TLS_PROXY=true`, or a non-loopback bind logs a warning.
  Sessions are capped and expire when idle, failed bearer attempts are throttled per client address,
  and a preview can only be applied from the session that created it.
- MCP requests are served at **`POST /mcp`** (Streamable HTTP; the session id is returned in
  the `Mcp-Session-Id` response header and must be echoed on subsequent `GET`/`DELETE`).
- Guards run in order on `/mcp`: `Origin` allowlist → `Host` allowlist → bearer token. CORS is
  never treated as authentication.
- `GET /healthz` is an unauthenticated liveness probe that reveals no secrets:

```bash
curl -s http://127.0.0.1:3919/healthz
# {"status":"ok","server":"newegg-marketplace-mcp","version":"0.1.0"}
```

| `newegg_listing_apply_create`   | **W** Submits exactly the previewed listing feed.                                                                                   |

Where:

- **`Identifier`** = `{ type: "sellerPartNumber" | "neweggItemNumber" | "upc"; value: string (1–64); condition?: Condition }`.
- **`Update`** = `{ identifier: Identifier; quantity: integer >= 0; warehouseLocation?: string; fulfillmentOption?: "Seller" }`.
- **`Condition`** ∈ `new | refurbished | usedLikeNew | usedVeryGood | usedGood | usedAcceptable`.
- **`ServiceDomain`** ∈ `contentmgmt | ordermgmt | datafeedmgmt | servicemgmt | reportmgmt | sellermgmt | sbnmgmt | shippingservice`.
- **Order `status`** ∈ `unshipped | partiallyShipped | shipped | invoiced | voided | paymentPending`; **`type`** ∈ `all | sbn | sbs | multiChannel | nws`; **`premierOrder`** ∈ `all | premierOnly | noPremier`. `dateFrom`/`dateTo`/`lastUpdatedAfter` take either an ISO 8601 instant with `Z` or a numeric offset (converted to Newegg Pacific time) or a zone-less string, which is a Pacific wall clock as `YYYY-MM-DD HH:mm:ss` or `MM/DD/YYYY HH:mm:ss` (sent unchanged, so the server's time zone never shifts the window); a bare `YYYY-MM-DD` is a Pacific calendar day and expands to `00:00:00` for `dateFrom`/`lastUpdatedAfter` and `23:59:59` for `dateTo`; any other form is rejected before any request. An unknown `status` or a blank or whitespace-padded `countryCode` is rejected too, never ignored.

The preview `updates` array is bound to `NEWEGG_MCP_MAX_ITEMS_PER_OPERATION` (default 500) at
registration time via a Zod `.max(...)`, so an oversized request is rejected by the tool's own
input schema.

**Preview semantics.** The stored preview records the **requested** strategy (`direct` |
`feed` | `auto`) so apply replays exactly what was planned, while the preview's returned
`strategy` field is the SDK's **resolved** decision (`direct` | `feed` | `mixed`).
`includeCurrentInventory` is accepted and forwarded to the SDK (reads only, never a write) but
is not surfaced in the tool's output.

## Environment variables

> **Breaking (0.1.x, T-5665 to T-5675): security hardening.** The report file download requires explicit
> FTPS (set `NEWEGG_MCP_ALLOW_PLAINTEXT_REPORT_FTP=true` only if you must accept clear text);
> `NEWEGG_MCP_HTTP_BEARER_TOKEN` must be at least 32 characters or the server refuses to start; RMA
> `imageUrls` must be `https` without `user:password@`; a preview can only be applied from the MCP session
> that created it; the HTTP transport caps sessions and throttles failed bearer attempts. Details in the
> [repository README](../../README.md) and `docs/mcp-security.md`.

> **Breaking change in 0.1.0 (T-5911): credentials are now bound to a marketplace.** Newegg
> authenticates on `sellerid` + API key + secret key only and ignores the URL prefix, so keys issued
> for one marketplace's seller account (for example Newegg.ca) used with `NEWEGG_MARKETPLACE=us|b2b`
> silently read and write THAT account while labeling it `us`/`b2b`. The MCP server therefore refuses
> to start unless the credentials are labeled for the selected marketplace. **Migration:** either set
> `NEWEGG_<MP>_SELLER_ID`, `NEWEGG_<MP>_API_KEY` and `NEWEGG_<MP>_SECRET_KEY` (`<MP>` = `US`, `B2B` or `CA`;
> all three required) for the marketplace in `NEWEGG_MARKETPLACE`, or keep the unprefixed
> `NEWEGG_SELLER_ID`/`NEWEGG_API_KEY`/`NEWEGG_SECRET_KEY` and add `NEWEGG_CREDENTIALS_MARKETPLACE` set to the
> marketplace they were issued for (it must equal `NEWEGG_MARKETPLACE`). There is no fallback to another
> marketplace's set. SDK users should pass `credentialMarketplace` to `createNeweggClient`; omitting it
> keeps the old, unsafe behaviour. See ADR 0006.

| Variable                                       | Default                  | Meaning                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NEWEGG_SELLER_ID`                             | see below                | Legacy unprefixed Seller ID; needs `NEWEGG_CREDENTIALS_MARKETPLACE`.                                                                                                                                                                                                                                                        |
| `NEWEGG_API_KEY`                               | see below                | Legacy unprefixed API key (`Authorization` header).                                                                                                                                                                                                                                                                         |
| `NEWEGG_SECRET_KEY`                            | see below                | Legacy unprefixed secret key (`SecretKey` header).                                                                                                                                                                                                                                                                          |
| `NEWEGG_US_*` / `NEWEGG_B2B_*` / `NEWEGG_CA_*` | —                        | `SELLER_ID`, `API_KEY`, `SECRET_KEY` issued for that marketplace (e.g. `NEWEGG_CA_SECRET_KEY`). When any of the three is set for the selected marketplace all three are required; never used for another marketplace.                                                                                                       |
| `NEWEGG_CREDENTIALS_MARKETPLACE`               | —                        | Marketplace the unprefixed keys were issued for (`us` \| `b2b` \| `ca`); required with them and must equal `NEWEGG_MARKETPLACE`, else the server refuses to start.                                                                                                                                                          |
| `NEWEGG_MARKETPLACE`                           | — (required)             | `us` \| `b2b` \| `ca`. Selects the endpoint prefix AND the credential set (credentials belong to a seller account; Newegg ignores the prefix).                                                                                                                                                                              |
| `NEWEGG_MCP_ALLOW_WRITES`                      | `false`                  | Registers the write tools (inventory, pricing, listings, RMA, courtesy refund; preview + apply) when `true`.                                                                                                                                                                                                                |
| `NEWEGG_MCP_MAX_ITEMS_PER_OPERATION`           | `500`                    | Max items per preview/apply.                                                                                                                                                                                                                                                                                                |
| `NEWEGG_MCP_PREVIEW_TTL_SECONDS`               | `600`                    | Preview lifetime before expiry.                                                                                                                                                                                                                                                                                             |
| `NEWEGG_MCP_ALLOW_ZERO_QUANTITY`               | `true`                   | Allow quantity `0` (out-of-stock) writes.                                                                                                                                                                                                                                                                                   |
| `NEWEGG_MCP_MAX_PRICE_CHANGE_PERCENT`          | `50`                     | Largest absolute % change one price update may make vs the current price; bigger changes are blocked at preview. Plain decimal only (no `0x`, sign or exponent).                                                                                                                                                            |
| `NEWEGG_MCP_MAX_REFUND_AMOUNT`                 | `500`                    | Largest courtesy refund (or refund-RMA total) one preview may plan, in the marketplace currency; bigger is blocked at preview. Plain decimal only (no `0x`, sign or exponent).                                                                                                                                              |
| `NEWEGG_MCP_MAX_LABEL_AMOUNT`                  | `100`                    | Cap on one UPS label purchase (marketplace currency), a plain decimal (e.g. `100`, `49.99`). Over-cap and unquotable plans are blocked at preview, re-checked at apply; a reprint has no quote, so it is blocked while a cap is active unless `NEWEGG_MCP_ALLOW_LABEL_REPRINT=true`. `unlimited` or `off` disables the cap. |
| `NEWEGG_MCP_ALLOW_LABEL_REPRINT`               | unset (`false`)          | Exactly `true` lets a label reprint (no quote, may be charged) through the label cap, without lifting the create cap. Needs `NEWEGG_MCP_ALLOW_WRITES=true` (re-checked at apply). The two reprint limits below apply either way.                                                                                            |
| `NEWEGG_MCP_LABEL_REPRINT_COOLDOWN_SECONDS`    | `600`                    | Per-order cooldown for label reprints: a second reprint of the same order inside the window is refused at apply (and reported at preview). Whole number 1-86400; always on. In memory: resets on restart.                                                                                                                   |
| `NEWEGG_MCP_MAX_LABEL_REPRINTS_PER_HOUR`       | `6`                      | Label reprints allowed across all orders in any rolling hour, enforced at apply. Whole number 1-1000; always on. In memory: resets on restart.                                                                                                                                                                              |
| `NEWEGG_MCP_ALLOWED_WAREHOUSES`                | empty = all              | Comma-separated warehouse allowlist.                                                                                                                                                                                                                                                                                        |
| `NEWEGG_MCP_ALLOWED_MARKETPLACES`              | empty = all              | Comma-separated marketplace allowlist. If set, `NEWEGG_MARKETPLACE` must be included or the server refuses to start.                                                                                                                                                                                                        |
| `NEWEGG_MCP_HTTP_HOST`                         | `127.0.0.1`              | HTTP bind host.                                                                                                                                                                                                                                                                                                             |
| `NEWEGG_MCP_HTTP_PORT`                         | `3919`                   | HTTP bind port.                                                                                                                                                                                                                                                                                                             |
| `NEWEGG_MCP_HTTP_MAX_SESSIONS`                 | `32`                     | Concurrent HTTP sessions; the next `initialize` gets 503.                                                                                                                                                                                                                                                                   |
| `NEWEGG_MCP_HTTP_SESSION_IDLE_SECONDS`         | `1800`                   | A session idle this long is closed.                                                                                                                                                                                                                                                                                         |
| `NEWEGG_MCP_HTTP_BEHIND_TLS_PROXY`             | unset (`false`)          | Exactly `true` confirms a TLS proxy fronts the plain-HTTP listener; otherwise a non-loopback bind logs a warning.                                                                                                                                                                                                           |
| `NEWEGG_MCP_ALLOW_PLAINTEXT_REPORT_FTP`        | unset (`false`)          | Exactly `true` lets the report file download fall back to clear-text FTP (default: FTPS only).                                                                                                                                                                                                                              |
| `NEWEGG_MCP_HTTP_BEARER_TOKEN`                 | empty                    | Bearer token, at least 32 characters; required to bind a non-loopback host.                                                                                                                                                                                                                                                 |
| `NEWEGG_MCP_HTTP_ALLOWED_ORIGINS`              | empty = same-origin only | Comma-separated allowed `Origin` values.                                                                                                                                                                                                                                                                                    |
| `NEWEGG_MCP_HTTP_ALLOWED_HOSTS`                | empty                    | Comma-separated allowed `Host` values; loopback always allowed.                                                                                                                                                                                                                                                             |
